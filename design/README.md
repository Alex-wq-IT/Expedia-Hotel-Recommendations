# Expedia Dashboard Asset Pack

Prepared for an analytics/hackathon dashboard and presentation workflow.

## Contents

### `brand/`
- `expedia_logo_fullcolor_light_bg.svg/.png` — Expedia consumer wordmark + yellow mark, for light backgrounds.
- `expedia_mark_fullcolor_light_bg.svg/.png` — yellow Expedia mark only.
- `expedia_group_logo_fullcolor_light_bg.svg/.png` — Expedia Group logo.

These are viewport-isolated from the official public trademark artwork hosted by Expedia Group. Do not recolor, distort, redraw or treat them as your own brand.

### `icons/`
Curated open-source Font Awesome Free SVGs, grouped into:
- analytics
- travel
- ui

They are not Expedia proprietary icons. They are included because they are practical for dashboards and Expedia Group's public Careers design-system reference explicitly lists Font Awesome as an available icon source in that system.

### `docs/`
- original presentation brandbook
- dashboard-specific addendum

### `source/`
Original official trademark artwork downloaded from Expedia Group's legal site.

### `licenses/`
Font Awesome license.

## Recommended use in Figma

1. Import the SVGs rather than PNG when possible.
2. Keep the Expedia consumer logo on white or very light surfaces.
3. Use icons at 16–20 px; recolor only the open-source UI icons, not the Expedia logos.
4. Preferred icon colors: `#191E3B` default, `#1668E3` active.
5. Keep the dashboard visibly labeled as a hackathon/analytics prototype rather than an official Expedia application.
